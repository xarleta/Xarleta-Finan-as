# Xarleta Finanças V7 Consolidado

Esta é a versão consolidada das V2, V3, V4, V5 e V6.

## O que foi unificado

- Base funcional
- Contas
- Parcelamentos
- Metas
- Reservas
- Categorias
- Trabalho
- Análises
- Notificações
- Backup
- Exportação
- Biometria
- Configurações

## Importante

As versões anteriores tinham módulos adicionados em arquivos separados. Esta V7 reorganiza a base em um único projeto.

Antes de considerar o aplicativo pronto para uso, é obrigatório executar a etapa de validação técnica:
- flutter pub get
- flutter analyze
- flutter test
- teste no Android
- geração de APK

Não é correto declarar APK final sem essa validação.
